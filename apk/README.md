# release APK

- 파일: `도란의검_도란_release.apk` (팀명 도란의 검, 앱 이름 도란, 80MB)
- 설치: `adb install -r 도란의검_도란_release.apk`
- 테스트 환경: Pleos Connect 에뮬레이터 v2.1.0 (Android 14, API 34), 2560 × 1440, 160dpi
- 같은 파일이 [GitHub Release v1.0](https://github.com/team-drive-lab-26/drive-app/releases/tag/v1.0)에 `Doranui-Geom_Doran_release.apk`로도 있습니다(GitHub Release는 파일 이름의 한글을 지웁니다).

release APK는 인터넷에 올려 둔 AI 서버(`https://doran-agent.onrender.com`)에 붙습니다. 설치 뒤 실행 방법은 저장소 루트 [README](../README.md)를 보시면 됩니다.
