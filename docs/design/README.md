# 디자인

## 한 줄

여행 한 번 = 카세트테이프 한 개. 가는 길은 A면. 지나온 곳과 남긴 목소리는 녹음된 구간이고, 앞길은 아직 빈 테이프다.

## 화면마다 테이프가 하는 일

| 화면 | 테이프 |
| --- | --- |
| 정차 홈 | 화면 아래를 가로지르는 띠. 왼쪽에 들른 곳·목소리, 귤색 재생 헤드가 지금, 오른쪽 빈 테이프 끝에 목적지와 남은 시간. 도란은 헤드 위에 앉는다 |
| 정차 제안 | 헤드가 조금 왼쪽으로 물러나고, 카드가 빈 테이프 위에 놓인다. 카드마다 빈 테이프에 끼울 점선 칸이 하나씩 생기고 칸에 그곳 이름을 펜으로 적는다 |
| 주행 | 테이프가 자막 한 줄짜리 띠로 접힌다. 도란은 띠 왼쪽 끝에 작게(200dp 이하) 앉고 혼자 두리번거리지 않는다. 띠 하나에 말 한 줄만. 말하거나 듣는 동안에만 띠 오른쪽 끝에 작은 정지 아이콘 |
| 녹음 | 목소리가 실시간 파형으로 테이프에 적히고, 도란이 쓰기 헤드를 따라 움직인다. 고른 사람 색으로 남는다 |
| 음악 | 테이프 속지(A1, A2, A3 곡 목록). 재생 중인 곡은 테이프 색으로 뒤집히고 릴이 돈다 |
| 앨범 목록 | 테이프 등을 꽂아 둔 줄. 흰 라벨에 손글씨로 여행 이름 |
| 3D 지도 앨범 | 지도 위 길은 테이프 색 띠. 아래에 같은 여행 테이프가 깔리고, 핀과 테이프 구간 어느 쪽을 눌러도 같은 곳이 골라진다 |
| 처음 설정 | 새 테이프를 끼우는 장면. 비어 있는 테이프 끝에 "첫 여행" |

## 색 (`DoranPalette`)

| 이름 | 값 | 쓰는 곳 |
| --- | --- | --- |
| Background | `#CFE4EF` | 바탕. 창밖 하늘색 |
| Ink | `#14202B` | 글자, 주 버튼 |
| InkSoft | `#3D5364` | 보조 글자(바탕 위 대비 6:1 이상) |
| Tape | `#2A221E` | 녹음된 테이프, 재생 중 곡, 지도 위 길 |
| TapeBlank | `#433832` | 아직 비어 있는 앞길 |
| TapeText / TapeTextSoft | `#F7F2EC` / `#CBBFB4` | 테이프 위 글자 |
| Head | `#FF7A32` | 재생 헤드, 선택 표시. 도란 몸과 같은 계열 |
| Surface | `#FFFFFF` | 라벨 종이(카드, 곡 속지, 앨범 라벨) |

가족 리본 색(`FamilyRibbon`): 엄마 분홍, 아빠 하늘, 아이 노랑, 그 밖의 이름은 민트·라일락·살구·옥색 중 이름으로 고정. 같은 사람은 어느 화면에서나 같은 색이다.

쓰지 않는 것: 그라데이션 배경, 빛 번짐, 카드 격자, 제목 위 작은 영문 라벨, 이모지·유니코드 기호 아이콘(뒤로 가기 꺾쇠도 직접 그린다).

## 글자

- 본문·숫자: SUIT(Regular, SemiBold, ExtraBold). 시각·초·곡 번호는 고정폭 숫자(`tnum`)
- 테이프 라벨: 나눔펜. 장소 이름과 남긴 사람 이름에만 쓴다. 30sp 이상
- 크기: 주행 자막 38sp(한 줄), 제목 30~40sp, 본문 18~20sp, 터치 영역 64dp 이상
- 글꼴은 `app/src/main/res/font/`에 들어 있고 둘 다 SIL Open Font License 1.1이다

## 움직임

- 주행·정차 화면은 같은 테이프 띠를 쓴다. 전환 때 띠가 펼쳐지고 접히는 애니메이션은 아직 없다
- 녹음 중 도란이 쓰기 헤드를 따라 테이프 위를 이동하는 것이 가장 큰 움직임
- 제안이 오면 헤드와 도란이 520ms 동안 왼쪽으로 물러나고 카드가 위에서 내려온다
- 주행 중에는 도란의 상태 표현(듣기·생각·말하기) 말고는 움직이지 않는다

## 정할 것

- B면(귀갓길 다시 듣기) 화면
