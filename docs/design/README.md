# 디자인

## 한 줄

화면이 곧 차 앞 도로다. 메뉴나 카드 목록 대신 3D로 펼친 앞길 하나에 정보를 세운다. 도란은 내 차 자리에 있는 주황 빛 원이다.

## 화면마다

| 화면 | 구성 |
| --- | --- |
| 정차 홈 | 화면 전체가 앞길. 길가에 앞으로 지날 휴게소가 거리만큼 떨어져 표지판으로 서 있고(가까우면 크게), 지평선 끝이 목적지와 도착 시각. 위 막대 왼쪽은 "○○까지" 아래 남은 시간(60sp)과 도착 시각, 그 아래 차 상태(배터리·탑승 인원). 오른쪽은 앨범·음악·설정 탭(아이콘과 이름, 72dp). 그 아래 도란의 말(44sp, 앞에 주황 점) |
| 정차 제안 | 제안한 곳이 왼쪽 길가에 주황 표지판으로 솟고, 오른쪽에 사진 패널(첫 곳은 사진 크게, 둘째 곳은 짧게)이 붙는다. 사진이 없거나 못 불러오면 사진 자리를 비우고 이름 옆에 업종 아이콘 칸(식당·카페·휴게소·관광지·행사·문화·레저·쇼핑)을 둔다. 그림이나 가짜 사진은 넣지 않는다. 이미 길가에 있는 휴게소면 그 표지판이 주황으로 바뀐다. 제안이 떠 있는 동안 다른 표지판은 걷힌다 |
| 도착·한마디 | 들른 곳에 세우면 그곳이 바로 앞 오른쪽 길가에 주황 표지판("지금 세운 곳")으로 서고, 오른쪽 패널이 "남길래"·"괜찮아"를 묻는다(마이크 아이콘, 72dp 버튼, 말로 "응"·"괜찮아"라고 해도 된다는 안내). 제안 카드가 떠 있으면 카드가 먼저다 |
| 경유지 | 내비에 경유지가 들어가면 경로선이 그곳을 거쳐 가도록 휘고, 표지판에 "경유지"가 붙는다. 도착하면 다시 곧게 |
| 주행 | 같은 앞길에서 표지판과 패널이 모두 걷힌다. 하늘 자리에 자막 한 줄, 내 차 자리에 도란. 말하거나 듣는 동안만 오른쪽 아래에 작은 정지 아이콘. 도란은 혼자 숨쉬거나 흔들리지 않는다 |
| 녹음 | 가운데 도란이 마이크 소리만큼 출렁이고, 둘레를 따라 15초가 주황으로 찬다 |
| 음악 | 왼쪽에 지금 곡(재생 중이면 그 곡, 아니면 도란이 가장 권하는 곡) 이름을 크게, 아래 아티스트·분위기, 재생/일시정지(104dp)와 다음(80dp). 오른쪽 패널에 도란이 권한 곡(주황 점)부터 기기에 넣어 둔 곡 전체. 곡 이름·아티스트는 음원 태그, 분위기는 서버 추천 카드에서 온다. 재생 중에는 차선이 천천히 흐른다 |
| 앨범 목록 | 지나온 길. 최근 여행일수록 가까운 길가에 표지판으로 서 있다. 표지판을 고르면(굵은 테두리) 오른쪽 패널에 그 여행에서 들른 곳과 남긴 목소리가 세로 길로 이어지고, "지도 앨범 열기"나 같은 표지판을 한 번 더 누르면 3D 지도 앨범. 여행이 셋보다 적으면 다음 자리에 점선 표지판("다음 여행"), 여행이 없으면 점선 표지판 하나와 안내 문장 |
| 3D 지도 앨범 | 비스듬히 눕힌 지도 위 주황 경로선과 핀. 아래 '지나온 길' 막대에 들른 순서대로 점. 핀이나 점 어느 쪽을 눌러도 같은 곳이 골라진다 |
| 처음 설정 | 아직 아무것도 서 있지 않은 빈 앞길과 도란, 왼쪽 위 인사(52sp), 오른쪽 패널에서 마이크·위치·녹음을 아이콘과 함께 알리고 동의 |
| 설정 | 왼쪽은 빈 앞길, 오른쪽에 설정 패널(호출어 스위치, 화면 자동·낮·밤 한 줄 선택, 가족 이름, 보내는 것, 앱 정보). 화면을 바꾸면 뒤의 길이 바로 그 시간대로 바뀐다 |

## 앞길 장면 (`RoadScene`)

- 하늘: 위에서 지평선으로 옅어지는 세 단 그라디언트. 지평선 위로 빛이 번진다(낮은 엷은 볕, 밤은 먼 도시)
- 산: 겹산 세 줄. 멀수록 하늘색에 묻히고(대기원근), 길이 지나는 가운데는 낮게 파인다
- 길: 멀수록 옅어지는 아스팔트에 고정된 결, 가장자리 실선, 세 차로를 나누는 점선(원근에 맞춰 길이·굵기가 준다), 바깥 자갈 띠, 양쪽 가드레일과 기둥 반사판
- 밤에는 전조등이 닿는 가까운 길과 차선만 밝다. 도란의 주황 빛이 그 아래 길바닥에 비친다
- 와이퍼가 돌면(차량 값) 하늘이 회색으로 가라앉고 길이 젖어 하늘과 도란 빛이 길게 비친다. 움직이는 비는 그리지 않는다
- 정차 홈(제안이 없을 때)·처음 설정·음악 재생 중에만 차선이 아주 천천히(8초에 한 칸) 다가온다. 주행 화면에서는 멈춰 있다

## 차량 상태

- 배터리(%)와 탑승 인원(안전벨트를 맨 좌석 수)은 정차 홈 위 막대 남은 시간 아래 한 줄. 차가 값을 주지 않으면 줄이 없다
- 배터리 20% 이하면 그 줄이 주황으로 "충전이 필요해"를 붙이고, 휴게소 패널 안내에 전기차 충전소가 있으면 "여기서 충전할 수 있어"를 앞에 꺼낸다
- 전조등은 화면 자동 모드의 낮·밤을, 와이퍼는 젖은 길을 정한다. 주행 화면에는 차 상태를 따로 띄우지 않는다

## 도란

얼굴, 눈, 잎 없는 주황 빛 원(`DoranCharacter`).

- 대기: 천천히 숨 쉬듯 커졌다 작아진다
- 듣는 중: 운전석 쪽으로 쏠리고 마이크 소리만큼 가장자리가 출렁인다
- 생각 중: 가장자리를 따라 빛이 돈다
- 말하는 중: 목소리 크기만큼 물결이 바깥으로 퍼진다
- 기쁨(경유지 추가, 녹음 저장): 한 번 크게 맥박친다

## 움직임

- 정차로 바뀌면 표지판 기둥이 땅에서 자라고 판이 떠오른다. 가까운 것부터 차례로
- 주행·정차 화면은 같은 지평선과 도란 자리를 써서, 바뀔 때 길은 그대로 있고 표지판·패널만 걷히거나 솟는다(320ms 겹침)
- 경유지가 생기면 경로선이 0.9초 동안 곧은 선에서 휜 선으로 넘어간다
- 주행 중에는 도란 상태 표현 말고 움직이는 것이 없다

## 색 (`DoranPalette`)

밤(기본)과 낮 두 벌. 구조는 같고 색만 바뀐다. 설정 > 화면에서 자동(07~19시 낮)·낮·밤을 고른다.

| 이름 | 값 | 쓰는 곳 |
| --- | --- | --- |
| Background | `#0B1018` | 바탕(하늘) |
| Road / RoadEdge | `#161E2A` / `#2E3A4C` | 길, 길 가장자리 |
| Surface / SurfaceHigh | `#151C27` / `#1B2431` | 패널, 표지판 |
| Ink / InkSoft / InkMute | `#EEF2F7` / `#A5B0C1` / `#7F8A9C` | 글자 |
| Accent | `#FF7A32` | 도란, 경로선, 제안 표지판, 주 버튼 |

낮: 하늘 `#E8EDF2`, 길 `#4A5361`(흰 차선), 패널·표지판 흰색, 글자 `#10151C`, 주황 `#F26A1F`.

앞길 장면 색(밤 / 낮): 하늘 위 `#03060B` / `#9FB3C6`, 지평선 `#1C2636` / `#EEECE5`, 먼 산 `#151E2B` / `#BDC7CF`, 가까운 산 `#0A1018` / `#7F8C93`, 길 먼 쪽 `#1B2331` / `#8C949D`, 길 가까운 쪽 `#0E141C` / `#3A424C`, 가드레일 `#2B3544` / `#B4BCC4`. 파랑은 낮 하늘 위쪽에만 엷게 쓴다.

아이콘(`DoranIcons`)은 글리프 대신 같은 굵기 선으로 직접 그린다: 표지판(앨범), 음표, 조절 막대(설정), 사람, 재생·일시정지·다음, 마이크, 핀, 목소리, 업종 여덟 가지.

가족 색(`FamilyRibbon`): 엄마 분홍, 아빠 하늘, 아이 노랑. 목소리를 남긴 핀과 점에 쓴다.

## 글자

- SUIT(Regular, SemiBold, ExtraBold). 시각·거리·초는 고정폭 숫자
- 한글 제목은 어절 단위로 줄을 바꾼다(`LineBreak.WordBreak.Phrase`)
- 크기: 주행 자막 40sp(한 줄), 정차 남은 시간 60sp, 도란의 말 44sp, 큰 제목(곡 이름·인사) 52sp, 제목 30~36sp, 본문 18~20sp, 터치 영역 64dp 이상(위 막대 탭·뒤로 72dp)
- 글꼴은 SIL Open Font License 1.1

## 데이터

- 앞길 휴게소 표지판은 서버 `POST /v1/route/ahead`에서 받는다(내비 경로가 있을 때 1분마다). 서버가 남은 시간과 출발 후 시간으로 지금 위치를 추정해 앞으로 나올 휴게소와 남은 km를 준다
- 내비가 없는 에뮬레이터 촬영에서는 시연 값(하남드림 12km, 횡성 68km)을 쓴다(`--es demo tape`)
- 제안한 장소는 경로를 따라 간 거리를 몰라서 가까운 쪽부터 순서대로 세운다
- 앨범 화면 촬영용 여행 기록은 시연 값이다(`server/demo_trips.json`, 여행 세 번: 오늘·40일 전·89일 전). 실제 여행 기록이 아니며, 촬영 스크립트가 `seed_album.py --backdate`로 빈 상태 → 여행 하나 → 여럿 순서로 넣어 찍는다
- 제안 카드 사진은 관광공사 데이터의 `image_url`이다. 강릉 장소 182곳 중 97곳만 사진이 있고 휴게소는 사진 필드가 없다. 주소는 http로 오지만 https로도 열려서 앱이 https로 바꿔 부른다
- 에뮬레이터에는 차량 서비스가 없어 배터리·탑승 인원·와이퍼를 디버그 인텐트로 넣어 찍는다(`--es battery 15 --es seats 3 --es wiper on`)
