# 디자인

## 한 줄

화면이 곧 차 앞 도로다. 메뉴나 카드 목록 대신 3D로 펼친 앞길 하나에 정보를 세운다. 도란은 내 차 자리에 있는 주황 빛 원이다.

## 화면마다

| 화면 | 구성 |
| --- | --- |
| 정차 홈 | 화면 전체가 앞길. 길가에 앞으로 지날 휴게소가 거리만큼 떨어져 표지판으로 서 있고(가까우면 크게), 지평선 끝이 목적지와 도착 시각. 위 막대는 남은 시간과 앨범·음악·설정 |
| 정차 제안 | 제안한 곳이 왼쪽 길가에 주황 표지판으로 솟고, 오른쪽에 사진 패널(첫 곳은 사진 크게, 둘째 곳은 짧게)이 붙는다. 이미 길가에 있는 휴게소면 그 표지판이 주황으로 바뀐다. 제안이 떠 있는 동안 다른 표지판은 걷힌다 |
| 경유지 | 내비에 경유지가 들어가면 경로선이 그곳을 거쳐 가도록 휘고, 표지판에 "경유지"가 붙는다. 도착하면 다시 곧게 |
| 주행 | 같은 앞길에서 표지판과 패널이 모두 걷힌다. 하늘 자리에 자막 한 줄, 내 차 자리에 도란. 말하거나 듣는 동안만 오른쪽 아래에 작은 정지 아이콘. 도란은 혼자 숨쉬거나 흔들리지 않는다 |
| 녹음 | 가운데 도란이 마이크 소리만큼 출렁이고, 둘레를 따라 15초가 주황으로 찬다 |
| 음악 | 곡 세 개. 도란이 가장 권하는 첫 곡만 채운 버튼, 재생 중인 곡은 막대가 움직인다 |
| 앨범 목록 | 지나온 길. 최근 여행일수록 가까운 길가에 표지판으로 서 있다. 표지판을 누르면 그 여행의 3D 지도 앨범 |
| 3D 지도 앨범 | 비스듬히 눕힌 지도 위 주황 경로선과 핀. 아래 '지나온 길' 막대에 들른 순서대로 점. 핀이나 점 어느 쪽을 눌러도 같은 곳이 골라진다 |
| 처음 설정 | 아직 아무것도 서 있지 않은 빈 앞길과 도란, 오른쪽 패널에서 동의 |

## 도란

얼굴, 눈, 잎 없는 주황 빛 원(`DoranCharacter`).

- 대기: 천천히 숨 쉬듯 커졌다 작아진다
- 듣는 중: 운전석 쪽으로 쏠리고 마이크 소리만큼 가장자리가 출렁인다
- 생각 중: 가장자리를 따라 빛이 돈다
- 말하는 중: 목소리 크기만큼 물결이 바깥으로 퍼진다
- 기쁨(경유지 추가, 녹음 저장): 한 번 크게 맥박친다

## 움직임

- 정차로 바뀌면 표지판 기둥이 땅에서 자라고 판이 떠오른다. 가까운 것부터 차례로
- 주행·정차 화면은 같은 지평선과 도란 자리를 써서, 바뀔 때 길은 그대로 있고 표지판·패널만 걷히거나 솟는다(320ms 겹침)
- 경유지가 생기면 경로선이 0.9초 동안 곧은 선에서 휜 선으로 넘어간다
- 주행 중에는 도란 상태 표현 말고 움직이는 것이 없다

## 색 (`DoranPalette`)

밤(기본)과 낮 두 벌. 구조는 같고 색만 바뀐다. 설정 > 화면에서 자동(07~19시 낮)·낮·밤을 고른다.

| 이름 | 값 | 쓰는 곳 |
| --- | --- | --- |
| Background | `#0B1018` | 바탕(하늘) |
| Road / RoadEdge | `#161E2A` / `#2E3A4C` | 길, 길 가장자리 |
| Surface / SurfaceHigh | `#151C27` / `#1B2431` | 패널, 표지판 |
| Ink / InkSoft / InkMute | `#EEF2F7` / `#A5B0C1` / `#7F8A9C` | 글자 |
| Accent | `#FF7A32` | 도란, 경로선, 제안 표지판, 주 버튼 |

낮: 하늘 `#E8EDF2`, 길 `#4A5361`(흰 차선), 패널·표지판 흰색, 글자 `#10151C`, 주황 `#F26A1F`.

가족 색(`FamilyRibbon`): 엄마 분홍, 아빠 하늘, 아이 노랑. 목소리를 남긴 핀과 점에 쓴다.

## 글자

- SUIT(Regular, SemiBold, ExtraBold). 시각·거리·초는 고정폭 숫자
- 한글 제목은 어절 단위로 줄을 바꾼다(`LineBreak.WordBreak.Phrase`)
- 크기: 주행 자막 40sp(한 줄), 제목 30~36sp, 본문 18~20sp, 터치 영역 64dp 이상
- 글꼴은 SIL Open Font License 1.1

## 데이터

- 앞길 휴게소 표지판은 서버 `POST /v1/route/ahead`에서 받는다(내비 경로가 있을 때 1분마다). 서버가 남은 시간과 출발 후 시간으로 지금 위치를 추정해 앞으로 나올 휴게소와 남은 km를 준다
- 내비가 없는 에뮬레이터 촬영에서는 시연 값(하남드림 12km, 횡성 68km)을 쓴다(`--es demo tape`)
- 제안한 장소는 경로를 따라 간 거리를 몰라서 가까운 쪽부터 순서대로 세운다
