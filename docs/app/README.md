# 앱 설계

[확정]은 코드에 반영된 것, [예정]은 아직 정해야 하는 것입니다. 정하면 [확정]으로 바꾸고, 방향이 바뀌면 `docs/planning/decisions.md`에도 한 줄 남깁니다.

## 역할

- [확정] 무엇을 제안할지는 서버/AI가 판단하고, 앱은 차량·내비 신호를 모아 보내고 받은 결과를 실행한다
- [예정] 경유지와 길안내 화면은 Pleos 내비 앱이 맡는다. 도란은 요청만 보내고 결과를 음성 한 줄로 알린다
- [예정] 좌표 근처 판정, 도착 위치 판정 같은 보정 로직은 시연에 꼭 필요할 때만 넣는다

## 코드 구조

- [확정] 단일 모듈, 단일 Activity, Compose, Navigation Compose(타입 안전 경로)
- [확정] 화면은 `feature/<이름>`에 두고 feature끼리 참조하지 않는다
- [확정] 공통 코드는 `core/model`, `core/network`, `core/data`, `core/designsystem`, `core/trip`, `core/voice`, `core/media`로 나눈다
- [확정] 의존성은 `AppContainer`에서 직접 만든다(Hilt 안 씀)
- [확정] UI 상태는 ViewModel의 StateFlow 하나로 내리고, 화면은 `collectAsStateWithLifecycle`로 받는다
- [확정] 판단 로직은 시간을 밖에서 받는 순수 Kotlin으로 짜고 단위 테스트를 붙인다
- [예정] Pleos SDK는 `core/data`, `core/voice`의 래퍼에서만 import한다. 연결이 안 되면 예외 대신 "미연결" 상태를 낸다
- [예정] 정차 화면을 만들 때부터 feature마다 ViewModel을 둔다. 화면을 넘나드는 여행 흐름은 `TripCoordinator`에 둔다
- [확정] 디버그 막대, 디버그 패널, 시연 버튼은 debug 빌드에서만 보인다
- [예정] 앱이 직접 말하는 문구(오류, 안내)는 한 파일에 모은다

## 화면

- [확정] 기어 D/R이면 주행 화면, P/N이면 정차 화면으로 바뀐다
- [확정] 주행 중에는 버튼 없이 도란, 자막 한 줄, 위쪽 길 정보 한 줄만 보인다. 도란을 누르면 듣는다
- [확정] 정차 화면의 첫 화면은 도란 홈이다(`feature/character`). 위쪽 글자 링크로 앨범·음악·설정에 간다
- [확정] 정차 중 제안은 도란이 왼쪽으로 비켜서고 카드(사진, 경로에서 거리, 한 줄 설명) 최대 2장이 들어온다. "들르기"·"괜찮아" 또는 말로 답하고, 주행으로 바뀌면 바로 닫는다
- [확정] 처음 켜면 처음 설정 화면에서 마이크·위치·녹음 사용 범위를 알리고 동의를 받는다. 동의 뒤에 마이크 권한을 묻는다
- [확정] 녹음 화면은 들어오면 바로 15초 녹음하고, 끝나면 "누가 남겼어?"에서 가족 이름을 고른다(이름은 설정에서 바꾼다)
- [확정] 음악 화면은 들어오면 지금 어울리는 곡 세 곡을 받아 와 목록으로 보여 준다
- [확정] 앨범은 여행 목록 → 3D 지도 앨범. 지도는 다녀온 길을 비스듬히 눕힌 종이 지도에 그리고, 들른 곳마다 핀을 세운다. 목소리를 남긴 곳은 주황 핀이고 누르면 다시 듣는다
- [확정] 디버그 빌드에서 도란을 길게 누르면 디버그 패널이 열린다. adb 인텐트로 화면·기어·표정을 바꿀 수 있다(`MainActivity.handleDebugIntent`)

## 차량·내비

- [확정] 기어·문은 Pleos Vehicle에서 받는다
- [확정] 경로, 남은 시간, 도착은 Pleos NaviHelper에서 받는다
- [확정] 출발, 도착 30분 전, 재탑승, 110분 연속 운전 이벤트를 앱이 판단해 서버로 보낸다
- [확정] 내비 도착 후 P로 세우면 정차 기록(`stop`)을 서버에 보낸다
- [확정] 경유지는 장소 번호가 없어도 좌표로 넣는다(에뮬레이터에서 확인)
- [예정] 집 위치를 설정에서 받을지, 시연에서는 고정값을 쓸지 정한다

## 음성

- [확정] 듣기·말하기는 Pleos STT/TTS(ON_DEVICE)를 쓰고, 안 되면 Android 기본 음성으로 바꾼다
- [확정] 마이크 권한을 받으면 계속 듣고, 문장 앞에 "도란아"가 있을 때만 처리한다(기획안 호출어). 대기 중에 들은 말은 화면에 보이지 않고 서버로 보내지 않는다
- [확정] "도란아"만 부르면 효과음과 "응?" 뒤 다음 한 문장을 듣고, "도란아, 휴게소 어디야"처럼 붙여 말하면 바로 처리한다
- [확정] 호출어는 일반 음성 인식 결과에서 찾는다(`core/voice/WakeWord`). 잘못 받아 적히는 표기(또란, 도랑, 두란)도 인정하고, 문장 중간의 "도란"은 부른 것으로 보지 않는다
- [확정] 도란이 말하는 동안은 마이크를 끄고, 다 말하면 대기로 돌아간다
- [확정] 확인이 필요한 제안(`needs_confirmation`)을 말한 뒤에는 호출어 없이 바로 답을 듣는다
- [확정] 듣는 중에는 이벤트 제안이 끼어들지 않는다(그 제안은 건너뛴다)
- [확정] 음성 버튼은 호출어가 안 될 때의 예비 수단으로 남긴다
- [확정] 녹음 화면은 녹음 전 `TripCoordinator.pauseStandby()`, 끝나면 `resumeStandby()`를 부른다
- [확정] 내비 도착 뒤 정차하면 "○○에 도착했어. 여기서 한마디 남길래?"라고 묻고, "응"이면 녹음 화면을 연다
- [예정] 에뮬레이터에서 "도란"이 어떻게 받아 적히는지, 부르고 대답까지 몇 초 걸리는지 확인한다
- [예정] 정차 중 15초 음성 캡슐을 녹음하고, 누가 말했는지 고른다
- [예정] 녹음 파일은 기기에 저장하고 서버에는 기록(`capsule`)만 보낸다. 서버 파일 업로드 API가 아직 연결되지 않았기 때문이다
- [예정] 재탑승 제안("한마디 남길래?")에 답하면 녹음 화면을 연다

## 서버·데이터

- [확정] 서버 호출은 Retrofit 3, OkHttp, kotlinx.serialization
- [확정] 대화 맥락은 서버 메모리, 여행 기록은 서버 SQLite에 둔다
- [예정] 여행 1번에 세션 ID 1개를 쓰고 기기에 저장해, 앱을 다시 켜도 같은 여행이 이어진다
- [예정] 서버로 보내는 시간은 항상 한국 시간 기준으로 만든다
- [예정] 앨범은 서버 여행 기록 조회 API로 보여 준다

## 음악

- [확정] 곡 재생은 앱의 Media3 재생기가 맡는다. 앱 안의 `assets/music/<track_id>.mp3`를 튼다
- [확정] 어떤 곡을 고를지는 서버가 정하고, 앱은 `PLAY_MUSIC`의 `track_id`만 받아 튼다
- [예정] Pleos에 음악 추천·스트리밍 API가 없고, 외부 음원(iTunes 미리듣기, 음악 앱 연결)은 네트워크와 저작권 문제가 있어 쓰지 않는다
- [예정] 저작권 표시 없이 쓸 수 있는 무료 음원 9~12곡을 앱에 넣는다. 파일 이름과 `tracks.json`의 `id`를 같게 맞춘다
- [예정] 곡마다 분위기 태그(`travel`, `bright`, `refresh`, `calm`)와 가족 태그(예: 지우가 좋아하는 곡)를 붙인다. 곡 수가 적어도 "왜 지금 이 곡인지"를 말할 수 있게 하기 위해서다
- [예정] 정차 중에는 세 곡 카드를 보여 주고, 말("첫 번째 거")이나 터치로 고른다
- [예정] 주행 중에는 카드 없이 한 곡만 말로 알리고 바로 튼다
- [예정] 곡 목록(`ai/data/<지역>/tracks.json`)은 AI·서버 담당이 채우고, 앱은 같은 ID의 음원 파일을 넣는다

## 디자인

- [확정] 바탕은 밝은 회색, 글자는 먹색, 색은 도란 몸(무광 주황)과 선택된 것에만 쓴다(`DoranPalette`). 그라데이션 배경, 빛 번짐, 카드 격자는 쓰지 않는다
- [확정] 도란은 귤 모양 캐릭터(`DoranCharacter`)다. 눈 두 개와 꼭지 잎이 있고, 상태를 몸과 눈으로 보여 준다: 대기(숨쉬기·깜박임), 듣는 중(운전석 쪽으로 기울고 눈이 커짐, 마이크 크기에 반응), 생각 중(눈이 위로 돎), 말하는 중(목소리 크기만큼 몸이 눌림·입), 기쁨(웃는 눈·뜀, 경유지 추가·녹음 저장 때)
- [확정] 라이트 테마부터 만들고, 야간은 같은 구조에서 색 토큰만 바꾼다
- [확정] 주행 자막 34sp, 본문 18sp 이상, 터치 영역은 최소 64dp
- [확정] 공통 컴포넌트는 `core/designsystem`에 `Doran` 접두어로 둔다(`DoranStage`, `DoranPrimaryButton`, `SuggestionCard`)
- [확정] 3D 지도 앨범은 지도 SDK 없이 Canvas 원근 투영으로 그린다. 열 때 위에서 내려다보다 비스듬히 눕는다

## 품질

- [예정] 머지 전에 빌드와 단위 테스트(JDK 21), 에뮬레이터 시연 시나리오 1회를 확인한다
- [예정] 앱은 죽지 않는다. 연결 실패는 자막 한 줄로 알리거나 조용히 넘어간다

## 시연 범위

- [예정] 출발 → 휴게소 제안·경유지 추가 → 정차·재탑승 → 음악 → 음성 캡슐 → 앨범 순서로 보여 주고, 여기에 없는 기능은 뒤로 미룬다
