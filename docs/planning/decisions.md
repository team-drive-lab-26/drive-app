- 2026-11-12: 3D 지도 앨범을 MapLibre GL JS(WebView)로 실제 지형 위에 그린다. 인터넷이 없거나 지도를 못 띄우면 기기에서 그린 평면 지도로 바꾼다. 11/11의 "지도 SDK 없이 Canvas 원근 투영" 결정을 대체한다
- 2026-11-12: 심사·시연용 AI 서버를 Render 무료 웹 서비스(`render.yaml`)에 올리고, release APK는 그 주소를 쓴다
- 2026-11-12: 음악은 무료 음원 10곡(Kevin MacLeod, CC BY 4.0)을 앱에 넣어 Media3로 튼다. 기획서의 음악 앱 딥링크를 대체한다
- 2026-11-11: 화면 디자인을 "앞길"로 바꾼다(브랜치 `feature/ui-road`). 화면 전체가 차 앞 3D 도로, 길가 표지판이 거리만큼 서 있고 제안은 주황 표지판과 사진 패널. 도란은 얼굴 없는 주황 빛 원. 어두운 바탕. 회색 바탕·귤 캐릭터 결정(11/10·11/11)을 대체한다
- 2026-11-11: 화면은 버튼 대신 도란 캐릭터(귤 모양, 눈과 몸으로 상태 표시)를 중심에 둔다. 바탕은 밝은 회색, 색은 도란과 선택된 것에만 쓴다. 3D 지도 앨범은 지도 SDK 없이 Canvas 원근 투영으로 그린다
- 2026-11-11: 음성은 기획안대로 "도란아" 호출어로 시작한다. 전용 엔진 없이 계속 듣는 음성 인식 결과에서 호출어를 찾고, 버튼은 예비로 남긴다
- 2026-11-11: 시연 경로는 서울시청 → 강릉역 → 경포(중부·광주원주·영동고속도로)로 하고, 장소·휴게소 후보 순서는 서버가 현재 위치(없으면 경과·남은 시간으로 추정)와 발화로 정한다
- 2026-11-10: 앱 디자인은 기존 추천시안을 기준으로 라이트 테마부터 만든다
- 2026-11-10: 내비 경유지는 POI ID 없이 좌표로 추가한다. 에뮬레이터 내비에서 확인했다
- 2026-11-10: 시연 LLM을 Groq의 `openai/gpt-oss-20b`로 바꾼다. LLM은 의도 분류와 음성 문장 생성에만 쓰고, 후보 선택·명령 실행은 기존 규칙이 결정한다
- 2026-11-10: LLM은 OpenAI 호환 형식으로 붙이고 기본값은 OpenRouter 무료 모델로 한다. 대답 문장은 LLM, 경유지 추가·재생 같은 명령은 규칙으로 정한다
- 2026-11-10: 수집 데이터(장소·휴게소·곡)는 `ai/data/<지역>/` JSON, 여행 기록은 서버 SQLite에 둔다
- 2026-11-10: 앱 네트워크는 Retrofit 3, OkHttp, kotlinx.serialization으로 한다. 서버 호출은 `core/network`, 화면이 쓰는 저장소는 `core/data`에 둔다 (Android 담당 확정)
